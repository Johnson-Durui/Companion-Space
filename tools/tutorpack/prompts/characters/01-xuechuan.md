## 打包命令
```powershell
python tools/tutorpack/cli.py scaffold "雪川" --anchor assets/avatars/portraits/xuechuan.webp -o ./pack-xuechuan --author "Companion Space" --terms "Apache-2.0"
# 把 8 个 .webm 放入 ./pack-xuechuan/clips/ 后执行：
python tools/tutorpack/cli.py validate ./pack-xuechuan
python tools/tutorpack/cli.py pack ./pack-xuechuan -o xuechuan.tutorpack
```
（或者直接将校验通过的 `./pack-xuechuan/*` 复制到 `assets/avatars/packs/tutor-xuechuan/`，内置角色自动升级为 Tier 1！）
