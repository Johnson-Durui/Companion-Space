# Mobile brand assets

`app-icon-master.png` is an original Companion Space application icon generated
for this repository on 2026-08-12 with OpenAI's built-in image generation tool.
It depicts a friendly open-book companion and speech bubble using the product's
paper, teal, coral, and ink palette. It contains no third-party character,
franchise mark, text, or voice likeness.

The Android launcher icons, Android splash images, iOS AppIcon, and iOS splash
images are deterministic resized/composited derivatives of this master. The
master prompt requested a centered, vector-like, text-free application icon
with generous mobile mask safe area and no watermark.
