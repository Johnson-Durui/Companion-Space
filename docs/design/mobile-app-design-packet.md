# Companion Space 手机 App 设计包

## 设计命题

像一本有伙伴坐在旁边的学习手帐，而不是一套管理 AI 的后台。

角色负责温度，学习空间与复盘负责秩序。界面以暖纸张、墨绿行动色和珊瑚情绪色构成；不使用大面积玻璃拟态、发光渐变、后台指标墙或九宫格功能入口。

## 信息架构

手机端固定五项任务导航：

1. 今日：继续最近一次学习、今日任务和伙伴问候。
2. 空间：选择学习主题与资料边界。
3. 共学：从空间进入文字或实时陪伴。
4. 复盘：会话、复习项与已确认记忆。
5. 我的：伙伴、声音、本地保险箱、模型服务和高级设置。

技术概念不再作为一级导航。Vault 对用户显示为“本地保险箱”，Provider 显示为“模型与语音服务”。

## 渐进交互

- L0：底部导航只回答“现在要做什么”。
- L1：列表页只选择对象（空间、伙伴、复盘记录）。
- L2：详情页只完成这个对象的主要任务。
- L3：模型分配、许可、重置、诊断等进入二级设置或折叠区。

第一次启动按“保险箱 → 伙伴 → 空间 → 第一条文字消息”推进；真实模型、实时语音和资料导入是可选增强。

## 共学页

手机首屏只保留：返回与空间名、伙伴舞台、自然语言状态、字幕、主要输入动作。Transcript、板书、演示与诊断折叠；静音、打断、声音与结束不再作为五个同权按钮。输入区适配底部安全区，麦克风权限只在主动开启实时后申请。

## 情绪契约

七种情绪 `neutral / warm / cheerful / curious / focused / playful / concerned` 同时驱动：

- VRM expression 权重；
- 2D fallback 的眼睛、光晕与姿态；
- 浏览器兼容朗读的轻微语速与音高变化；
- 本地神经 TTS 的白名单情绪与受限语速韵律（固定声线，范围 0.5–2.0）；
- licensed runtime bridge 的 emotion 状态。

本地神经 TTS 仍走服务端 PCM，不在浏览器侧二次变调。Qwen3-TTS 0.6B
以确定生效的轻微语速变化为基础；自然语言风格指令只作为兼容增强，不能把它
宣传为该版本必然生效的完整情绪控制。

## 响应式

- 375px：单列、16px 页边距、底栏 `64px + safe-area`、二级内容用折叠区或 bottom sheet。
- 768px：单任务宽列或主从布局，空间列表可两列，详情抽屉从底部改右侧。
- 1440px：任务导航展开为窄侧栏；共学页可双栏，但伙伴、字幕和输入保持主视觉。
