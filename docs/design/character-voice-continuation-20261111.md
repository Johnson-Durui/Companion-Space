## 实施与验收范围

本轮集中完善角色工作室的试听体验，不新增依赖或模型权重。请求等待时临时显示 thinking，PCM 播放时显示 speaking；音频电平继续走现有 speech controller，不通过 React 逐帧刷新整个编辑器。试听完成或停止后恢复用户选择的手动状态。

停止、切换试听空间、改变声音或形象设置以及离开角色页时，浏览器中止试听请求，清空播放队列并归零口型。每次异步返回先验证请求仍有效；即使请求已无法及时终止，迟到结果也不能重新播放。该保证针对浏览器消费与播放，不等同于证明所有远端供应商都已停止推理。

验收需同时观察真实 Web Audio 的调度/停止和角色运行时状态，不能只检查按钮文案。自动化中的受控 PCM 是测试夹具，不用于证明真人实听质量或 Qwen GPU 性能。2D 仍为 reactive portrait，3D 仍复用现有 VRM，未新增 Live2D 或服务端数字人视频。

## 本轮验证

本轮实现及验证已完成。5 项角色试听回归通过，覆盖真实 2D 播放电平、已加载 VRM 的口型权重、停止后的归零与手动状态恢复、三种声音输入变更取消、并发迟到响应、换空间、SPA 离页及错误重试；原有完整 Mock 主旅程 1 项通过。类型检查、lint 和生产构建通过，独立代码审查没有发现阻断问题。
