# Companion Space v0.1 产品验收基线

本文件把 v0.1 的产品承诺映射为可执行验收项。任何页面数量或接口数量都不能替代这条用户闭环：

`解锁本地空间 → 接入模型 → 建立学习空间 → 导入资料 → 创建角色 → 语音/文字通话 → 画图与分步演示 → 查看引用与复盘 → 确认记忆`

## 用户、场景与问题

目标用户是在个人电脑上自托管、希望掌控资料与模型凭据，并想和可爱或 cool 的二次元搭子一起学习的单一设备拥有者。

核心场景是：用户围绕一个主题建立独立空间，导入自己的材料，选择模型和角色，在不上传摄像头画面的情况下实时对话，并在结束后保留可校对的学习结果。

当前要解决的问题：固定学科和固定角色无法承载个人知识体系；全局 Key 与共享知识库没有空间边界；非流式聊天缺少自然通话、打断与课后闭环。

## 范围与优先级

| 优先级 | 能力 | 可验收结果 |
| --- | --- | --- |
| P0 | 本地拥有者与凭据仓库 | 错误主密码无法解密；REST/WS 无拥有者会话时拒绝访问；响应、日志和导出物不出现明文 Key |
| P0 | 学习空间隔离 | 空间 A 的资料、会话、记忆、复习项和能力绑定无法从空间 B 读取或检索 |
| P0 | 无 Key 的 Mock 闭环 | 全新克隆可以完成建空间、资料、角色、通话、复盘，不依赖真实服务或真实 Key |
| P0 | 通话与隐私 | 支持字幕、文字兜底和打断；结束后磁盘、SQLite 与日志中没有原始音频 |
| P0 | 可信引用 | 引用只能对应服务器实际命中的当前空间片段；空知识库明确显示“未使用空间资料” |
| P1 | BYOK 模型中心 | 用户可创建、测试和按能力绑定连接；失败有明确原因且不静默跨厂商回退 |
| P1 | 角色工作室 | 角色配方覆盖身体、脸、发型、服装、配饰、颜色、人格、关系与声音；可复制、预览、导入导出 |
| P1 | 教学白板与分步演示 | 回合内板书（`board_actions`）即时渲染；"演示一下"可得到 ≥3 步、带板书与配音的 `LessonScript`，可暂停/步进/重播/打断；演示引用只能来自空间资料真实命中 |
| P1 | 复盘和记忆 | 最终字幕可查看；敏感记忆只有用户确认后成为长期记忆；复习项可编辑或删除 |

非范围：公共云账号、多用户协作、云同步、WebRTC、用户摄像头、AI 生成 3D、专业建模、真人数字人、完整离线模型包、自动课程和知识图谱、真实视频生成、手机局域网配对（连同一次性配对码与受信设备管理，推迟到 v0.2）。

## AI 失败回退

| 失败 | 产品行为 |
| --- | --- |
| 模型 401/403 | 标记连接需要更新凭据；保留用户输入；不展示或记录 Key |
| 模型 429 | 显示限流原因与重试入口；不自动切换其他厂商 |
| 模型超时/断流 | 结束当前生成并保留已确认字幕；允许文字重试 |
| 未绑定 STT/TTS | 通话房间降级为文字输入和文字回复，角色状态仍可用 |
| 麦克风拒绝 | 显示浏览器权限指引和文字输入入口 |
| VRM/WebGL 失败 | 使用 2D 立绘，不影响字幕、引用、打断和结束会话 |
| 索引失败 | 材料显示失败原因并允许重试；聊天明确本轮未使用该材料 |
| 模型输出格式错误 | 服务端拒绝伪造结构，返回安全的文字错误状态；不生成虚假引用 |
| 恶意资料指令 | 作为不可信文本处理，不改变系统角色、安全规则、凭据或空间边界 |
| Mermaid 渲染失败 | 板书降级为文本步骤卡片，不影响字幕、配音与打断 |
| 演示脚本格式错误 | 服务端拒绝该脚本并返回文字错误状态；不播放残缺演示，不生成虚假引用 |

## 指标与发布证据

- 激活：完成 `vault_initialized`、`provider_connected_or_mock`、`space_created`、`material_ready`、`character_saved`、`session_ended`、`recap_viewed` 的本地漏斗。事件不得携带文档正文、Prompt、字幕正文或 Key。
- 可靠性：API/WS 错误率、索引失败率、模型超时率、文字回退率、状态机非法转换次数。
- 质量：引用命中正确率、用户编辑复盘比例、记忆候选确认/拒绝比例、重新生成率。
- 性能：插话后本地播放停止 ≤250 ms；Mock 首段播放 <800 ms；支持设备角色渲染 ≥30 FPS；30 分钟会话无持续内存增长或音频残留。
- 发布证据：Ruff、Pytest、TypeScript、ESLint、Next build、Playwright、依赖审计和 Docker Compose 冒烟全部通过；真实 Key 仅进入人工矩阵，不进入 CI。

## 发布否决条件

出现任一情况不得标记 v0.1 完成：跨空间数据泄漏、明文 Key 落盘/进日志、原始音频残留、引用无法回溯到真实片段（含演示脚本中的引用）、无 Mock 全流程，或核心失败没有文字回退。
