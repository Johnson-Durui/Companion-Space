## 0. 为什么要重做体验

教学引擎、资料分析、学习者模型、计划、语音、纯视频老师都已经做出来了（M0–M8、V1–V3）。现在的界面是把这些能力**按开发顺序挂到页面上**，所以它能用，但像演示品。2026-11-21 的实测（基线截图在 `docs/rebuild/review/U-baseline/`）归结为六个根因：

| # | 根因 | 一个最直观的证据 | 本规格的回应 |
| --- | --- | --- | --- |
| R1 | 界面是"功能面板"，不是"旅程" | 课程页从上到下是 学习设置（折叠）→ 导入 → 分析 → 地图；个性化计划藏在折叠的"学习设置"里；没有首页 | §3、§4、§5.1–5.5 |
| R2 | 老师只活在一个路由里 | 新用户点的第一个主按钮"看一节示例课"进去是纯文字回放，没有老师；访谈是一个文本框 | §2 的 E1、§5.8、§5.12、§5.14 |
| R3 | 课堂是一张会滚动的网页，不是一通电话 | 出题时页面高 3110px（视口 900px）；站点导航常驻；手机上 9:16 视频被裁成横条 | §5.6 |
| R4 | 没有"手感层" | 可复用组件只有 3 个；二十多个原生下拉、5 处浏览器确认框；字体没有随应用提供；答题对错只是一行灰字 | `spec/design-system.md`、§5.14 |
| R5 | 系统在说话，不是老师或产品在说话 | "估算并开始分析""模型角色""Sidecar""Tier 3""0 token""Render failed"；一级导航里有连通性自检页"试聊" | §6 |
| R6 | 个性化与进步看不见 | 计划的原因、版本、被推迟的内容，下课后的计划重排，课上换了讲法，复习题的对错与下次时间——引擎都做了，界面都没显示 | §7、§5.4、§5.6.6、§5.7、§5.9–5.11 |

另有四处已在运行中复现的行为错误，U0 必须修：

1. **一次性动作被盖成表扬片段。** 答错、点"我不会"、点"没听懂 / 讲慢点 / 再讲一遍"（本应是安抚）、点"给点提示 / 举个例子"（本应是托腮）之后，形象播放的都是表扬片段。实测：判定为"再想想"时 `data-action="gentle_encourage"` 而 `data-clip="react_praise"`，持续约 2.6 秒。根因在形象包的"姿态 → 片段"表把"反馈"姿态固定映射到表扬片段，而课堂在触发动作后又下发了该姿态。
2. 状态显示"在想"时形象仍在播放讲话片段。
3. 第一次进课堂、还没开始时，状态显示"已暂停"。
4. 判定之后、老师还在讲评时，状态又变回"等你回答"（服务端顺序是 判定 → 新一拍开始 → 讲评 → 新问题，而界面要到新一拍开始才清掉上一个问题）。

## 1. 设计逻辑：一条闭环，七个时刻

所有者的原始设想是一条闭环。每个时刻学生心里有一个问题，界面的任务就是回答它并给出**唯一的下一步**。

| 时刻 | 学生心里的问题 | 界面回答 | 唯一主动作 | 老师此刻在做什么 |
| --- | --- | --- | --- | --- |
| ① 相遇 | 谁来教我？我会喜欢吗？ | 老师画廊：会动、会说话、有性格 | 就选 TA | 自我介绍、打招呼 |
| ② 交资料 | 我的教材和真题给谁？ | 一个大的投放区，自动识别类型 | 把资料放进来 | "交给我，我先读一遍" |
| ③ 被读懂 | 它真的看懂我的资料了吗？ | 老师口吻的进度 + 结果卡 | 继续 | 读资料（进度可见） |
| ④ 被了解 | 它知道我的水平和目标吗？ | 老师面对面问几个问题 + 几道摸底题 | 回答 | 提问、倾听、记下来 |
| ⑤ 拿到计划 | 我该怎么学？为什么这么排？ | 排到考试日的计划，每节都有理由，放弃了什么也说清楚 | 开始第一节课 | 讲解计划 |
| ⑥ 上课 | 我听得懂吗？卡住了怎么办？ | 一通视频通话：老师、白板、随时打断；换讲法、回头补，都说出来 | 听、答、说"没听懂" | 讲、问、听、换讲法 |
| ⑦ 回来 | 今天学什么？我进步了吗？ | 今天页：今天的课、到期复习、离考试几天、保住了多少分 | 开始上课 / 开始复习 | 记得你、等你 |

闭环之外只有两件事：**换老师 / 调人设**（随时）和**设置**（尽量不需要）。闭环也有尽头：课都上完了或考试过了，界面要有交代（§5.4）。

三个推论：

- **个性化必须是主路径。** 现在最显眼的按钮是课程地图上的"开始或继续这节课"，它绕过访谈、摸底和计划。重做后主路径是 ②→③→④→⑤→⑥，"直接学某个知识点"降为次级入口。
- **"它在为我调整"要说出来。** 计划变了、掌握度变了、课上换了讲法或回头补了前面的知识点，都有一句由数据拼出来的话。
- **老师是界面的主语。** 能用老师第一人称说的，就不用系统第三人称说。

## 2. 体验原则（设计与验收的裁决依据）

- **E1 老师在场。** 每个主要界面都有老师（视频小窗、头像或声音）。加载、空状态、等待、出错都是老师出场的机会。
- **E2 一屏一个主动作。** 每个界面最多一个主按钮（强调色实心），由"当前处于闭环的哪一步"决定。
- **E3 上课即通话。** 课堂占满一屏、不出现页面滚动条、控制条固定、站点导航隐藏；老师在听、在想、在讲，任何时刻一眼可辨。
- **E4 一百毫秒内有回应，每一段等待都有名字。** 点击立即有按压反馈；超过 0.4 秒的等待显示进行中状态；超过 2 秒的等待说明在做什么；超过 10 秒的任务说明进展并允许离开。**没有真实进度数据时不显示百分比**，用动效加已等待时长。
- **E5 证据可见。** 掌握度、进度、计划理由、计划变化都来自作答证据和计划数据，并且显示出来；界面不自行下"已掌握"的结论。
- **E6 人话优先，细节下沉。** 默认界面不出现 token、Tier、Sidecar、模型角色、向量检索这类词；技术细节收进"详情"或"高级"。
- **E7 诚实。** 降级、失败、未验证都要可见，并给出修复入口；不为了好看而隐藏问题，不编造进度或数据。
- **E8 不问第二遍。** 学生说过的（称呼、节奏、目标）不再问；老师记得。

## 3. 信息架构

### 3.1 三种外壳

| 外壳 | 用在哪里 | 特征 |
| --- | --- | --- |
| **书桌外壳 AppShell** | 今天、课程及其二级页、老师、设置 | 浅色；顶部导航；内容区最大宽度 1200px |
| **专注外壳 FocusShell** | 首次引导、课程准备流程、复习会话、练习与模考、课后小结、解锁 | 浅色；只有 Logo、当前流程名、进度和"退出"；内容居中最大 880px；没有全局导航；允许纵向滚动 |
| **课堂外壳 StageShell** | 候课、课堂、示例课、课堂回放 | 深色；占满视口（`100dvh`）；没有站点导航；见 §5.6 |

### 3.2 全局导航（AppShell）

顶栏从左到右：品牌标志（点击回"今天"）→ 导航四项 **今天 / 课程 / 老师 / 设置** → 右侧**老师小卡**（当前老师头像 + 名字，点击去"老师"页）与**本机状态点**（悬停或点击显示"只在本机运行"与 AI 服务是否就绪）。

- "试聊"从一级导航移除，最终并入"设置 › AI 服务"的"测试对话"。
- 进入子页面时导航保持高亮（`/courses/...` 高亮"课程"）。
- 手机宽度下导航变为底部标签栏。
- 会话未解锁（主密码）时不显示导航。

导航各项的落地时间见任务单（U1：课程 / 老师 / 设置 + 状态点只显示"只在本机运行"；U3：加入"今天"与就绪状态；U4：老师小卡）。

## 4. 动线

### 4.1 第一次使用

目标（可度量）：**一分钟内看到老师讲课**（示例课，不需要任何配置）；**用仓库自带的示例资料、手里已有密钥，十分钟内上到第一节课**；用自己的资料时不承诺时长，但**等待期间始终知道进展、始终有事可做**。

1. 启动后进入 `/welcome`。**第一屏就是老师画廊**。选中一位，TA 做自我介绍。主按钮"就选 TA"。
2. 选定后老师打招呼。两个去向：主按钮"开始准备我的第一门课"，旁支"先看一节示例课（不用配置）"。
3. **怎么称呼你**（一屏一个输入框，可跳过）。节奏、反馈方式留给访谈，不在这里问。
4. **连接 AI 服务**（向导，§5.2）。可选择"稍后再说"。
5. **第一门课**：起名 → 进入课程准备流程（§5.5）。

**"第一次使用"的判定**：本机设置里有一个"首次引导完成时间"（新增字段，见 §8 B9）。它为空且没有任何课程时，访问 `/` 重定向到 `/welcome`；在引导里选择"稍后再说"或建了第一门课即写入。此后 `/` 永远是今天页，没走完的步骤由今天页的引导清单承接。升级前就已有课程的用户视为已完成。

### 4.2 每天回来

打开即"今天"页：老师问候 + 今天的课（一键开始或继续）+ 到期复习 + 考试倒计时与已保住分值。多门课时每门课一行。

### 4.3 一节课

今天页或计划里点"开始上课" → **立刻进入候课界面**（老师、今天讲什么、选语音或文字、麦克风自检）→ 接通 → 上课 → 下课 → **课后小结**。

- **备课的等待要看得见。** 现在点"开始上课"后，如果这节课还没备好，请求会一直挂着（实测一次备课约 65 秒），学生只看到按钮上的"老师正在备课…"。改为：点击后立刻进入候课界面，老师处于"备课"状态；这段时间正好做课前热身；备好后"开始"按钮亮起（§8 B12）。备课没有真实的分段进度数据，**不显示百分比**，显示动效、已等待时长和"通常一分钟左右"。计划里最近两节课通常已提前备好，此时直接可以开始。
- **课前热身只有一种形态：嵌在候课界面里。** 有与这节课相关的到期复习卡时，候课面板下半部分给出"先热身几张"（最多 5 张，可随时跳过）。不再有"先去复习页、再进课堂"的中转。
- 上课方式记住上次的选择（记在浏览器本地）；暂停后恢复不再重新选择。

### 4.4 复习与练习

复习：今天页或课程"复习"页进入 → 一张一张做 → 每张答完看到对错、解析、下次什么时候再见 → 结束页汇总。
练习与模考：计划项进入 → 开始页 → 一题一屏 → 交卷 → 结果页。

### 4.5 出问题时

- **没连 AI 服务**：需要模型的主按钮（让老师读资料、开课）说明"先连接 AI 服务"，点击打开连接向导；不让学生点下去再报错。不需要模型的事（上传资料、点选访谈选项）照常可做。
- **课堂断线**：舞台上出现"连接中断，正在重连…"遮罩和"立即重试"；不要求学生刷新页面。**本机服务重启过**时遮罩说明"本机服务重启过"，设了主密码的给出解锁入口，解锁后回到课堂（能否从断开处继续，取决于 U2 对后端恢复能力的核实结果，见任务单）。
- **切走标签页**：立刻释放麦克风。**离开不到 30 秒回来，自动接着上，不需要点任何按钮**；超过 30 秒进入暂停，回来时舞台上显示"你离开了一会儿，已为你暂停 · 继续上课"。
- **能力降级**（语音不可用、形象降档）：toast 说明原因 + 修复入口；课堂继续。老师的声音默认依赖在线语音合成，断网或该服务不可用时老师只有画面和文字，界面明确提示。
- **被服务商限速**：访谈回退到点选控件（不需要模型）；读资料自动重试并在进度里说明"服务商限速，稍等"。

## 5. 逐屏规格

每屏写法：目的 → 结构 → 状态 → 数据来源 → 验收要点。标 **[B n]** 的是需要后端配合的项（汇总在 §8）。

### 5.1 今天（`/`）

**目的**：回答"今天学什么"，一键开始。样张：`reference/mockups/today.html`。

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [老师小窗 9:16，静态立绘]   晚上好，小林。                              │
│                            今天有 1 节课和 6 张复习卡。                 │
│                            〔老师的问候语气泡〕                         │
├────────────────────────────────────────────────────────────────────────┤
│ 今天的课   [课程名]                                                     │
│  {课题}                         约 25 分钟 · 第 7 / 18 节               │
│  考试权重 ▓▓▓▓▓░ 高   当前掌握 ▓▓░░░░ 还不稳   这部分考得多……          │
│                                                    [ 开始上课 ]        │
├──────────────────────────────┬─────────────────────────────────────────┤
│ 到期复习  6 张               │ 距{考试名} 23 天                        │
│ 约 5 分钟     [ 开始复习 ]   │ 预计已保住 42 / 100 分  ▓▓▓▓░░░░░│目标 85 │
├──────────────────────────────┴─────────────────────────────────────────┤
│ 这一周  ● ● ○ ● ○ ○ ○        这周学了 3 天                （U5 加入）   │
└────────────────────────────────────────────────────────────────────────┘
```

- 问候语是模板 + 数据（时段、称呼、今天的课数、到期卡数）；气泡里是当前老师自己的问候语（角色数据，缺省时不显示气泡）。
- "今天的课"的按钮是全页唯一主按钮。有进行中的课堂时文字为"继续上课"。
- 理由句由计划数据拼出（§7.1）。
- 多门课：每门课一张卡片，按考试日期由近到远排序；主按钮只给第一张。
- **没有考试日期的课程**：不显示倒计时与保分条，改显示"已学 {x} / {y} 个知识点"和次级入口"补上考试日期"。
- **今天没有课 / 学完了 / 考试已过**：见 §5.4 的对应状态，今天页用同一套状态。
- **首次使用**（没有课程，或第一门课还没走到计划）：问候区保留，下面换成**引导清单**——① 选一位老师 ② 连接 AI 服务 ③ 把第一门课的资料放进来 ④ 让老师认识你 ⑤ 上第一节课。每步有完成标记，只有当前步有"继续"按钮；旁边常驻"先看一节示例课"。

**状态**：加载用同形骨架；仪表盘请求失败显示错误卡片和"重试"，不得静默不显示。

**数据来源**：课程仪表盘（每行附带旅程状态与目标分 **[B9、B15]**）、默认老师、学习者昵称。"这一周"一行依赖进度数据，随 U5 加入。

### 5.2 首次引导与连接向导

**首次引导（`/welcome`，FocusShell，四步，顶部有步骤进度，每步可返回）**

1. **选老师**：画廊见 §5.12。主按钮"就选 {name}"。
2. **怎么称呼你**：一个输入框 + "继续" + "跳过"。保存后老师用新称呼问候一次。称呼的取值规则：以这里（即"设置 › 我"）填的为准；老师资料里的"怎么称呼你"只在它留空时生效。
3. **连接 AI 服务**：连接向导。可选"稍后再说"，并明确告诉学生哪些事暂时做不了（老师读资料、上课），哪些可以做（看示例课、选老师、上传资料）。
4. **第一门课**：课程名（必填）+ 学习目标（可选）→ 创建后进入 `/courses/:id/setup`。

**连接向导 ConnectWizard**（首次引导第 3 步与"设置 › AI 服务"共用）

- 第 1 步 **选服务**：卡片网格。每张卡片：服务名、一句话说明、标签"有免费额度""国内可直连"、能力图标（讲课 / 读资料 / 检查答案 / 看图 / 语音，来自预设里各能力是否有模型）。顶部两个筛选："先用免费的""要稳定和速度"。
- 第 2 步 **拿密钥**：先显示这家服务的 2–3 步图文指引（来自预设数据的可选字段，例如"注册并登录 → 打开密钥页面 → 点创建并复制"）；服务商页面上的原词（如 "API Key"）**原样出现一次**并注明"就是这里说的密钥"，否则学生到了对方网站找不到要点什么。然后是"打开网站获取密钥"按钮（新窗口）与粘贴框（可显示 / 隐藏）。服务地址、连接名称收在"高级"里并已预填。
- 第 3 步 **自动测试**：保存后自动测试，逐项显示结果："讲课 ✓ / 读资料 ✓ / 检查答案 ✓ / 看图 ✗（这家不支持，可以以后再补一家）"。失败项给人话原因（按错误码映射）和"检查密钥"按钮。测试进行中可取消。自动测试会发真实请求并计入用量，向导里要说明。
- 第 4 步 **结论**：一句话"可以开始上课了"或"还差一项：……"，主按钮回到来处。

后端在保存预设时已经自动把模型分配到未分配的能力上——向导只是把这件事说出来。手动分配与额外参数留在"设置 › AI 服务 › 高级"。

**就绪状态 `useReadiness()`**：由已有接口在前端推导出五项：能讲课 / 能读资料 / 能检查答案 / 能看图 / 能语音。供今天页、课程准备流程、开课按钮、顶栏状态点、设置页使用。

### 5.3 课程列表（`/courses`）

卡片网格（桌面两列、手机一列）。每张卡片：课程名、目标、**阶段感知的一行状态**（"还差资料""老师正在读资料""等你和老师聊一聊""今天：{课题}""今天的课上完了""学完了"）、三个小数字（知识点 / 真题 / 距考试天数）、一个按钮（文字随阶段变化）。卡片带状态属性供测试断言（不比对文案）。右上角"更多"菜单：重命名、课程设置、删除（确认对话框写明课程名与后果）。

"新建课程"用对话框。空状态由老师出场。

### 5.4 课程中枢与二级页（`/courses/:courseId/...`）

**课程头部**（所有二级页共用）：面包屑 → 课程名 → 一行摘要（考试名与倒计时、保分条；没有考试日期时是"已学 x / y 个知识点"）→ "更多"菜单（课程设置、重命名、删除）→ **标签栏：今日 / 计划 / 地图 / 复习 / 进度 / 记录 / 资料**。

**今日（默认页）**：按旅程状态分四种呈现。

- *准备中*（还没有计划）：横向的**旅程步骤条**（放资料 → 读资料 → 认识你 → 摸底 → 计划），标出完成、进行中、未开始、等待（例如"读完资料后开放"），下面是唯一主按钮"继续准备"，进入 `/setup` 的对应步骤。
- *学习中*：老师问候条 + "今天的课"卡（同 §5.1）+ 到期复习卡 + **接下来三节**（点"查看完整计划"去计划页）+ 最近一次计划调整的提示条（7 天内有调整时）。
- *今天的课上完了*：完成状态 + "提前学下一节""去复习""看看进度"三个次级动作。
- *学完了 / 考试已过*（计划项全部完成，或考试日期早于今天）：老师一句总结（模板：上了 {n} 节课、掌握了 {x} / {y} 个知识点、保住约 {s} 分）+ 三个动作："继续复习到期的卡""补上暂缓的 {k} 个知识点"（有暂缓时为主按钮）"设一个新的考试日期，重新排计划"。考试当天倒计时显示"今天考试"，之后不再显示天数；不出现负数倒计时，也不再显示"今天的课上完了"。

**课程设置**（"更多"菜单 → 对话框）：课程名、学习目标、目标类型、考试名称与日期、目标分、每周学习日、每次时长、老师划过的重点。显式保存；保存后提示"计划会按新的设置重排"并使计划缓存失效。它承接了原来"学习设置"面板里与课程有关的字段。

**计划（`/plan`）**

- 顶部**计划说明条**：上次调整的时间和原因（原因只映射代码里真实存在的取值：第一次生成 / 你手动重排 / 你完成了一节课 等；"置顶""顺延"是原地修改、不产生新版本，说明条不为它编造版本）。有上一版时显示"查看这次改了什么"（提前、延后、新增、暂缓的条目）**[B4b]**。
- 时间线按周分组；今天的项高亮。每项：日期、标题、类型徽标（新课 / 练习 / 模考，按类型取本地化文案，不显示后端的英文标题）、分钟数、状态。
- 每项可展开"为什么排在这里"：每个知识点一行，两条小横条——**考试权重**与**当前掌握**（§7.1）；老师划过重点的知识点带标记。
- 每项的动作：开始（主按钮只给今天的第一项）、置顶并固定、顺延、取消固定。重排后被移动的条目有位移动画，并用 toast 说明结果。
- **暂缓区**：因为时间不够而没排进来的知识点，以及"这些内容约占卷面 {weight}%"**[B4a]**；旧计划没有占比数据时不显示占比。
- 没有考试日期时，时间线没有日期列，说明条写"没有设考试日期，按每周 {n} 天、每次 {m} 分钟往下排"。
- 没有计划时：空状态说明还差哪一步，按钮去 `/setup`。

**地图（`/map`）**

- 两个视图切换：**按章节**与**按考试权重**（知识点按卷面占分从高到低的横向条形榜，带趋势箭头）。
- 每个知识点一行：名称、**掌握状态标记**（未学 / 在学 / 不稳 / 已掌握，取后端的状态，前端不另算）、考试权重小条、真题数。
- 右侧详情：类型、名称、摘要（公式、题干、解析统一用白板的文本渲染，不显示公式源码）、**前置关系小链**、统计（难度用点阵图标）、"查看依据"（折叠：资料原页与来源质量）、关联真题（链接到资料页的真题分区）。
- 动作：有计划时"学这个知识点"为次级样式并注明"会插到今天"；没有计划时上方提示"先让老师认识你，课会按你的情况来讲"并给"去准备"按钮，此时不出现醒目的开课按钮。"修订"收进"更多"菜单，删除用确认对话框。
- 选中的知识点写进 URL，从课堂返回后仍停在原处。
- 请求失败时显示真实错误与重试；只有"尚未生成"才显示"读完资料后会出现在这里"。

**资料（`/materials`）**：投放区（拖入时高亮）、已上传资料列表（每行：名称、页数、类型、状态、"移除"——读资料进行中禁用并说明原因）、读资料状态卡（已有地图时默认收起为一行，按钮"读新增的资料"）、**真题**分区（按年份列出已读入的真题卷，点开看题目与关联的知识点，沿用现有的真题浏览、换成新组件）。

复习、进度、记录见 §5.9、§5.11、§5.8。U3 期间地图、复习、进度、记录四页只是原样挂到新标签栏下，内容在 U5 重做。

### 5.5 课程准备流程（`/courses/:courseId/setup`，FocusShell）

五步，顶部步骤条；每步只做一件事，屏幕上只有一个主按钮。**读资料**与**认识你**并行：资料一交出去就开始读，学生不用等，直接进入访谈。

**第 1 步 放资料**

- 整屏一个大投放区（拖入高亮）+ "选择文件" + "粘贴文字"。
- 每个文件一行：名称、大小（小于 0.1 MB 显示 KB）、自动识别的类型（可改）；类型是真题时再出现年份、考试名称、是否含答案。
- 主按钮"交给老师"：上传并**自动开始读**。预计用量低于确认阈值时直接开始；超过阈值时弹确认，用人话表达规模（"这些资料比较多，会消耗较多 AI 用量"），用量数字放在"详情"里。
- **没连 AI 服务时仍可放入并上传资料**；主按钮文字为"先连接 AI 服务，老师才能开始读"，连接成功后自动开始读，不需要再点一次。

**第 2 步 读资料**（后台进行，可离开）

- 主视觉是老师（思考循环）+ 一句进度。进度句是**带占位符的模板**（"我在{阶段}，已经整理出 {数量} 个知识点"），占位符只填后端返回的阶段与计数；后端没给计数时用不带数字的模板。后端的原始进度文本只放在"查看详情"里。
- 进度用**四个大阶段**表达：读资料 → 整理知识点 → 看真题 → 准备摸底题。它们与现有十个阶段的对应关系由执行者在 U3 开工时读文案文件与后端的阶段枚举后写进 `DECISIONS.md`：按现有顺序连续分组，每个旧阶段恰属于一个大阶段。十段细节与"从这一步重试"保留在"查看详情"里。
- 显示大致剩余时间：按已完成阶段的实际耗时估算；估不出时写"通常需要几分钟到十几分钟，取决于资料多少"。
- 页面主按钮："趁这会儿，先和老师聊聊"（进入第 3 步）。访谈做完而资料还没读完时，给两个去处："看一节示例课""先逛逛老师"，并说明"读完我会在这里叫你"（今天页与课程卡片同步显示进展）。
- 完成时出**结果卡**，拆成两条文案：数量一条（几个单元、几个知识点、几套真题共几题）、"考得最多的是"一条（卷面占分前三的知识点）。有警告时在结果卡下方用人话列出，每条带建议动作。
- 失败时：人话原因 + "去检查 AI 服务" + "从这一步重试"。

**第 3 步 认识你（访谈）**

```text
┌──────────────────────┬──────────────────────────────────────────────────┐
│                      │  第 2 / 4 个问题                    跳过这个问题  │
│   [老师视频小窗]     │  ┌────────────────────────────────────────────┐  │
│    提问时讲话        │  │ 老师：这门课你是为了准备考试吗？什么时候考？ │  │
│    等回答时倾听      │  └────────────────────────────────────────────┘  │
│                      │  〔目标类型：备考 / 兴趣 / 补基础〕               │
│                      │  〔考试名称〕〔考试日期 选择器〕〔目标分〕        │
│                      │  也可以直接说：[ 自由输入……              ]       │
│                      │                                      [ 继续 ]    │
└──────────────────────┴──────────────────────────────────────────────────┘
```

- 老师的问题是气泡，并用**老师自己的声音**读出来（§8 B13；失败时显示"声音暂时用不了"并保留文字，不回退到浏览器合成音）。学生的回答也成为气泡。
- **每个主题的回答区 = 该主题字段对应的结构化控件 + 自由输入框**，两种都可以用。点控件提交时只带字段值、不调用模型，所以没连模型时访谈也能完成。

  | 主题 | 控件 |
  | --- | --- |
  | 你是谁 | 称呼（文本框，已填则预填）、当前阶段（选项卡片） |
  | 目标 | 目标类型（选项卡片）；选"备考"时再出现：考试名称、**考试日期（日期选择器）**、目标分（数字框，可留空） |
  | 时间 | **每周哪几天（周一到周日七个可多选芯片）**、每次多久（分段：20 / 30 / 45 / 60 分钟） |
  | 现在的基础 | 自评水平（选项卡片，来自现有枚举） |
  | 难点 | 单元多选芯片（资料读完后才有；没读完时只给自由输入并说明"读完资料后可以直接点章节"）、"老师划过的重点"（文本） |
  | 怎么教 | 讲法、节奏、反馈方式（选项卡片 / 分段） |

- 每个主题提交后，老师用一句模板复述记下的值（"记下了：12 月 14 日考试，每周一三五，每次 30 分钟"），旁边有"改一下"。
- **只问还不知道的（E8）**：进入访谈时，字段已有值的主题不再提问，老师用一句话确认并给"对 / 改一下"；顶部进度按实际要问的题数显示。第二门课起通常只问目标、时间、现在的基础、难点。实现方式：前端对已知主题用现有字段值直接提交该主题（只带字段值），不新增后端逻辑。
- 模型不可用时，每个主题的问题用文案文件里的固定问句（老师口吻，带称呼占位），仍由老师的声音读出；不显示"没有可靠抽取出答案"这类话。学生用自由输入回答但没识别出来时，老师说"我没太听明白，你可以点下面的选项"。
- 可以"跳过这个问题"，也可以"全部跳过，用默认值"。
- 原来的两张表单不再出现在流程里；访谈结果写入同样的字段，之后在"课程设置"与"设置 › 我"里修改（U7 之前"我"的字段留在现有设置页）。

**第 4 步 摸底**

- 资料没读完时这一步显示"读完资料后开放"和读资料的进展；**不得因为此时没有题而把摸底记为已跳过**（现有缺陷，§8 B3）。
- 一题一屏：题干、选项卡片、"提交""不会""够了，结束摸底"。顶部"已答 5 题"。作答后不显示对错（这是摸底，不是练习），只给一句承接并进入下一题。
- 结束后显示**起点图**：按单元分组的知识点方格，颜色与形状表示掌握状态；一句总结"较稳的是 {strongest}，优先补 {priority}"。因前置关系推断出来的用虚线边框标出。

**第 5 步 计划**

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ [老师小窗]  你的计划排好了。                                              │
│            离考试还有 23 天 · 每周 4 天、每次 30 分钟 · 一共 18 节课      │
│            有 3 个知识点排不进来，约占卷面 6%。  查看是哪些               │
├──────────────────────────────────────────────────────────────────────────┤
│ 本周                                                                      │
│  今天   {课题}            新课 · 25 分钟     ▸ 为什么排在这里             │
│  周三   {课题}            新课 · 30 分钟                                  │
│ 下周 ……                                                                   │
│                                          以后再说      [ 开始第一节课 ]   │
└──────────────────────────────────────────────────────────────────────────┘
```

没有考试日期时摘要改为"没有设考试日期，按每周 {n} 天、每次 {m} 分钟往下排"，并给次级入口"补上考试日期"。

**状态与数据**：步骤状态来自课程旅程接口 **[B9]**（不要为取状态去调用会触发模型的访谈接口）。

**验收要点**：每一步屏幕上只有一个主按钮；读资料期间可以做访谈；模型不可用时访谈六个主题都能只靠控件完成，完成后课程设置里考试日期与每周学习日有值；摸底不会被静默跳过；从选老师到看到计划，学生填写的项不超过约 10 项。

### 5.6 课堂（StageShell）

这是产品的心脏。目标：**像和老师打一通视频电话，旁边有一块白板**。样张：`reference/mockups/classroom.html`。

#### 5.6.1 布局（桌面，课堂根容器宽度 ≥ 1100px）

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ ←  {课题}    ▰▰▱▱ 要点 2/4 · {要点名}                    12:34   ▣   ？     │ 顶栏 48px
├───────────────────────┬──────────────────────────────────────────────────────┤
│   ┌───────────────┐   │ ┌──────────────────────────────────────────────────┐ │
│   │ ● 等你回答    │   │ │  白板（纸面，内部滚动，自动跟随）                │ │
│   │               │   │ │   ……                                             │ │
│   │   老师视频    │   │ │   当前讲到的行高亮                               │ │
│   │   9:16        │   │ │                              [ 回到最新 ↓ 2 ]    │ │
│   │               │   │ └──────────────────────────────────────────────────┘ │
│   │ {老师名}      │   │ ┌─ 作答托盘（纸面；出题时从下方滑出）─────────────┐ │
│   │ 字幕……        │   │ │ 题干……   [A ……] [B ……] [C ……]                    │ │
│   └───────────────┘   │ │ [确认答案] [我不会]              给点提示 看答案 │ │
│                       │ └──────────────────────────────────────────────────┘ │
├───────────────────────┴──────────────────────────────────────────────────────┤
│ (🎤) 免提 打断 │ [ 输入你的回答或问题……  ➤ ] 没听懂 举个例子 ⋯ │ 字幕 音量 课堂设置 记录 ⏸ 下课 │ 控制坞 76px，单行
└──────────────────────────────────────────────────────────────────────────────┘
```

- 整个课堂是 `100dvh` 的三行网格（顶栏 48px / 主区 / 控制坞 76px），**页面本身永不滚动**（课后小结相位除外，见 §5.7）。
- 主区两列。左列是老师舞台：视频框高度 = 主区高度，宽度按 9:16 计算，限制在 280–460px 之间；右列是白板，占满其余宽度；纸面上的文字行宽不超过约 40 个汉字（约 720px），图与表可用到 860px，整体居中。
- **矮视口**（常见笔记本缩放后浏览器视口只有 585–633px 高）：主区高度不足以按 9:16 给出 280px 宽时，视频框宽度固定 280px、高度取主区高度，画面裁切时保住脸（对齐顶部），不留黑边、不溢出。主区高度小于 400px 时自动切到"白板优先"视图。宽度上限 460px 生效时视频框在左列内垂直居中。
- 唯一的滚动容器是白板纸面内部（以及托盘的选项区）。
- 顶栏：返回（上课中点击先弹"暂停并离开？"）、课题、要点进度、已上时长（只在这里显示，视频框上不重复）、视图切换（**并排** / **白板优先**：老师缩为可拖动的小窗浮在白板一角；记住选择）、帮助与快捷键。
- 课堂根容器宽度 ≥ 1600px 时，对话记录可以作为第三列常驻。

#### 5.6.2 课堂相位（显式状态机）

把现在散落的条件判断换成一个相位函数，界面只根据它渲染。

**输入与出口（实现契约）**

`lessonPhase(input)` 是纯函数（可单测）。输入是一个显式对象，除了由事件重建出的课堂状态，还包括连接与本地状态：是否已连接、是否已开始、是否在恢复中、重连次数、是否在录音、**是否正在出声**（由语音输出的"本段开始出声"回调置真、段结束或被打断置假；文字上课时在该句显示期间置真）、是否有已请求但未出声的语音段、**待判定的提交**（学生提交了哪道题、何时）、最近一次判定、错误、是否因切走标签页而暂停、备课状态。这些值由课堂的状态钩子统一产出，组件里不再自己判断。

| 相位 | 何时 | 状态标识（文字 + 动效） | 形象 | 字幕区 | 控制坞 |
| --- | --- | --- | --- | --- | --- |
| `loading` | 取课堂数据 | — | 立绘骨架 | — | 不显示 |
| `preparing` | 这节课的教案还在准备 | "正在备课…"（动效 + 已等待时长） | 思考循环 | — | 不显示（候课面板，开始按钮未亮） |
| `lobby` | 已备好、还没开始过 | "等你上课" | 待机；点击开始后问候 | — | 不显示（候课面板） |
| `connecting` | 点了开始，等连接与第一个状态 | "正在进入课堂…" | 待机 | — | 禁用 |
| `thinking` | 已开始、没在出声、没在等回答 | "在想"（三点跳动） | **思考片段** | 三点跳动 | 可打字、可快捷回应 |
| `buffering` | 语音段已请求但还没出声 | "在想"（同上） | 思考或待机，**不播讲话片段** | 三点跳动 | 同上 |
| `speaking` | 正在出声（文字上课：该句显示中） | "在讲"（随音量跳动的声波条；文字上课不显示声波条） | 讲解 / 指白板 | 当前句 | "打断"可用 |
| `listening` | 学生正在按住说话，或免提检测到语音，直到这段话提交 | "在听"（随学生音量变化的波纹） | 倾听 | 识别中的文字 | 麦克风为"正在听" |
| `awaiting` | 有待回答的问题，且不在讲评期间 | "等你回答"；15 秒无操作后"安静陪你" | 倾听 → 待机 | 老师刚说完的那一句 | 作答托盘出现 |
| `judging` | 学生提交了带题目编号的作答、判定未到 | "在看答案"（转圈） | 倾听 | 保留 | 作答锁定 |
| `feedback` | 判定已到，直到新的问题出现 | "在讲" | 对：表扬一次性动作；错 / 部分对 / 不会：**安抚**一次性动作，然后讲解 | 讲评句 | 同 speaking |
| `paused` | 暂停，或切走标签页超过 30 秒 | "已暂停" | 待机（变暗） | — | 舞台上覆盖"继续"按钮 |
| `reconnecting` | 连接断开、正在重试 | "连接中断，正在重连…" | 静止 | — | 禁用；遮罩上有"立即重试" |
| `ending` | 点了下课、小结未到 | "正在整理小结…" | 道别动作 | — | 禁用 |
| `ended` | 小结已到 | — | 见 §5.7 | — | — |
| `failed` | 无法恢复的错误 | 人话原因 | 静止 | — | "重新连接""回到课程" |

规则：

- 第一次进入是 `lobby`（或 `preparing`），不是"已暂停"。判定"还没开始过"之前先核对：只建立连接、未点开始时事件序号是否会增长；会的话改用课堂状态与是否存在第一拍来判定。
- 学生开口时先停止老师的语音再进入 `listening`；这段话提交后，有待答问题则进入 `judging`（带选项题）或 `thinking`（开放回答），否则进入 `thinking`。
- `judging` 只在提交了带题目编号的作答后进入。**出口有四个，任一成立即离开**：收到该题的判定预告或判定；收到下一拍的讲话或新一拍开始；收到错误（回到 `awaiting` 并解锁托盘，显示可重试的错误）；超过 20 秒没有任何事件（回到 `awaiting` 并提示"老师还没回应，可以再提交一次"）。确认类提问（继续 / 换道简单的 / 今天到这）与开放回答不进 `judging`，提交后进入 `thinking`。
- `feedback` 从收到判定起，到**新的问题事件**为止；期间即使上一个问题还留在状态里，也不得显示"等你回答"。判定结果在新的问题到达时清空，**不在新一拍开始时清空**（服务端顺序是 判定 → 新一拍开始 → 讲评 → 新问题）。
- 不带判定结果的判定事件（"看答案"时返回的正确答案）不改变判定，只把正确答案显示到托盘；"部分对"按"再想想"的样式呈现并用现有的文案键。
- `speaking` 只在这一段真的开始出声之后才成立；之前是 `buffering`。
- **一次性动作播放哪个片段只由动作本身决定**；"反馈"姿态不再映射到任何片段（驱动收到它时保持当前片段）。对每一种一次性动作，先触发动作、再下发课堂实际会给的姿态，片段都必须是该动作对应的那一个。
- 形象由相位驱动。仓库里已有一套只被测试使用的编排状态机（`reduceChoreographer`）：要么把它扩成"相位 → 姿态"的唯一映射层，要么连同测试删掉，不得两套并存。新增"思考"姿态时同步处理姿态类型、姿态 → 片段表、循环短片驱动回基础片段的分支、静态驱动、按姿态写的样式；**向本地实时驱动的外部进程发送姿态时，把新姿态映射为协议已有的取值**，不改对外协议。缺片段时沿用驱动里已有的回退链。
- 单测必须覆盖：语音上课（讲评先由预览通路出声）、文字上课、出错后解锁、确认类提问不进 `judging`、同一题重问、看答案、部分对。

#### 5.6.3 候课、接通、暂停、下课

**候课面板**（`preparing` / `lobby`）

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ ←  回到课程                                                                  │
│                                                                              │
│        ┌───────────────┐        {课题}                                       │
│        │               │        约 25 分钟                                   │
│        │   老师视频    │        这节课会讲                                   │
│        │   （放大）    │         · {要点 1}  · {要点 2}  · {要点 3}          │
│        │               │                                                     │
│        │ ● 正在备课…   │        麦克风  ▂▃▅▂   试听老师的声音 ▷              │
│        │   已等 0:24   │                                                     │
│        └───────────────┘        [ 语音上课 ]   文字上课                      │
│                                 （备课中：按钮未亮，写明"备好就能开始"）     │
│   ─────────────────────────────────────────────────────────────────────────  │
│   先热身几张（最多 5 张，可跳过）   〔复习卡〕                    跳过热身   │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 要点列表来自教案 **[B1]**，备课完成后出现；没有时只显示课题。
- 备课中：老师说"我在备这节课，通常一分钟左右"，显示动效与已等待时长，**不显示百分比**；两个开始按钮未亮并写明原因。备课失败时给人话原因、"重试"和"去检查 AI 服务"。计划刚被重排、这个条目已经不存在时，回到课程"今日"并提示"计划刚更新过，请从这里重新开始"。
- 热身卡片嵌在面板下半部分（复用复习卡组件；U5 升级为带答后反馈的版本后这里自动获得）。没有相关到期卡时不显示这一块。
- 没配置语音识别时，语音按钮旁说明"可以听老师讲，但需要打字回答"，并给"去开启语音识别"。
- 回车等于主按钮。

**接通过渡**：点击后 300–500ms 的过渡（舞台从居中移到左列，白板从右侧滑入），老师问候。这段过渡同时盖住建立连接的时间，不出现通用转圈。

**暂停**：舞台上覆盖半透明层和一个"继续上课"大按钮；恢复时沿用原来的语音或文字方式。切走标签页导致的暂停见 §4.5（30 秒内回来自动继续；"你离开了一会儿"这一句只来自页面内存，刷新后按普通暂停显示）。

**下课**：自定义确认对话框——"现在下课吗？老师会整理今天的小结。"按钮"继续上课"（默认焦点）/"下课"。确认后进入 `ending`，老师道别。

#### 5.6.4 老师舞台（视频框叠层）

- 左上只放**状态标识**一枚（动效 + 文字，见相位表）；"基础画质"徽标是它右侧的一个 20px 图标（悬停或点击看原因）。视频框宽度小于 320px 时状态文字最长 5 个汉字。
- 左下、字幕之上是老师名字；字幕出现时名字淡出。
- 底部：字幕，优先一行、最多两行、每行不超过约 16–18 个汉字，字号随视频框宽度在 15–18px 之间，下垫半透明深色底保证对比度，不遮住老师的脸。字幕只显示老师说出的话。字幕开关在控制坞，开关状态被记住。
- 已上时长只在顶栏显示。
- 形象随声音有可见的变化：现在只有静态档有随音量变化的光环，**循环短片档也要有**（边缘柔光或声波条，颜色取老师主题色的深色版本）。
- 档位标签、计费信息从画面上移走，收进顶栏帮助旁的"画质与性能"浮层；降级时用 toast 说明原因并给修复入口。降级提示不得去掉，只换呈现方式。
- 片段切换不得露出静止底图：进入课堂后空闲时预取全部片段；新片段没解码出首帧之前旧片段继续播。

#### 5.6.5 文字上课

"文字上课"是候课面板上的两个入口之一，也是没带耳机、没配语音识别时的唯一方式，不能是残缺体验。

- 老师舞台下方（左列，视频框相应按 9:16 缩短，宽度不小于 280px）固定显示一块"老师刚才说的"区域：最近 3–4 句，最新一句高亮，可向上滚动回看本节全部。这是对话记录的只读最小版，U2 落地（完整的抽屉在 U6）。
- 字幕开关在文字上课时隐藏（文字就是主通道）。
- 每句的停留时间沿用现有按字数估算的规则；学生可按"下一句"（或空格）提前推进、按"等一下"停住。
- 形象在每句显示期间播放讲解循环，不显示声波条。

#### 5.6.6 白板

- **开场页**：第一块板书到达之前，白板不是一张空纸，而是这节课的"封面"——课题、要点列表（与候课面板同一份数据）、预计时长；第一块板书到达时封面上移成为第一页的页首。
- **自动跟随**：新内容出现时平滑滚到它；学生手动上滚后停止跟随，并显示"回到最新"浮标（带未读块数）；老师指向或标记某一行时把那一行带入视野。作答托盘出现或高度变化后，把当前焦点行（没有则最新一块）重新滚入可视区。减少动态效果时瞬时滚动。
- **当前焦点**：老师正在讲或指向的那一行强高亮（左侧色条 + 浅底色）；历史标记降为弱样式。指向标记画在目标行左侧，而不是块的右上角。
- **调整要看得见（R6）**：新一拍开始事件里已经带有教学动作与讲法。它们变化时，白板插入一条分节线，状态标识旁短暂出现同一句话（界面文案模板，不含学科内容）：换讲法 →"换个讲法再讲一遍：{讲法名}"；回补前置 →"先补一个前面的知识点：{知识点名}"；回到原处 →"回到刚才的地方"；同一要点第 n 次讲 → 分节线带"第 n 遍"。只映射事件里已有的字段，不新增后端逻辑；不认识的动作不显示。
- **分节标题**：阶段切换（开场 → 讲解 → 练习 → 小结）时插入一条分节线。
- **逐步揭示**：多步推导整块到达时按行依次显现（固定节奏即可）。
- **标记样式**：下划线、框选、着色三种都要画出来（数据里已有，现在被忽略）。
- **清板分页**：清板后旧内容成为"上一页"，白板右上角有页码与翻页；课中可以回看。
- **块级工具**（悬停或聚焦时出现）：复制、放大（函数图、图片、流程图进灯箱）。
- **行级"从这一行开始没跟上"**：悬停或聚焦某一行时在行尾出现小按钮（触屏下常显为淡色）；文本块也支持。
- **函数图**：配色取主题 token，每条曲线固定颜色并带图例；空心点和标注直接画在图上；容器尺寸变化时重绘。拖动缩放与"复位"是可选项。
- **流程图**：主题变量对齐配色与字体。**表格**：有边框、表头底色、数字右对齐。
- **渲染失败**：中文说明"这张图没画出来" + "查看原始内容"折叠；不直接显示源码和英文。
- 课堂里的纸面比书桌里的暗一档，避免晚上刺眼（取值见设计系统规格 §2.2，所有者在 U2a 看实物后确认）。

落地分期：开场页、自动跟随、当前焦点、调整提示与分节线、渲染失败说明、表格样式在 U2；逐步揭示、标记样式、指向到行、分页、块级工具、行级入口、图的主题在 U6。

#### 5.6.7 作答托盘

- 托盘是**纸面**（与白板同一张纸的延伸，上沿有分隔与轻阴影），从白板列底部滑出，白板内容区相应缩短。
- 结构固定三段：**题干区**（吸顶；最多 3 行，超出显示"展开"，展开时在托盘内滚动）、**选项区**（唯一可滚动的部分；出现滚动时底部有渐隐提示）、**操作行**（吸底：确认答案 / 我不会 / 给点提示 / 看答案，始终可见）。
- 托盘高度上限 = min(白板列高度的 60%, 白板列高度 − 160px)，即白板至少保留 160px。
- 选项是**选项卡片**：整张卡片就是承载单选 / 复选角色的元素，"键 + 文本"是它的内容，可访问名以"键 + 文本"开头；默认、悬停、聚焦、选中、锁定、正确、错误七态。**选中 = 强调色描边 + 选中标记，不用强调色实底；正确 / 错误 = 状态色浅底 + 图标（勾 / 叉）**——任何老师主题下，"选中"与"判定"都靠"描边 对 底色加图标"区分，不靠色相。选项文字都不超过约 12 个汉字且宽度足够时并排两到三列，否则单列。
- **出题期间题目的完整文本只在托盘里**；白板流里不同时渲染这道题。讲评开始后，托盘收起，题目变成白板里的一张**已作答卡片**（题干摘要、你的答案、判定徽标），可回看。
- 键盘：数字或字母键选择，回车提交。
- 语音或文字预填答案时，托盘提示"已替你填好，确认后再提交"（保留现有的先确认再判分）。
- 提交后按钮变为"正在看你的答案…"并转圈（`judging`）；判定预告一到，选中的卡片立刻变为正确或错误（错误时轻微左右晃动一次）；托盘内出现判定横幅（保留状态播报角色与现有判定文案键）。
- "看答案"不需要二次确认，但托盘里说明"看过答案的题不算你会了，老师会再出一道同类题"（这是现有规则，把它说出来）。
- 没有选项的开放提问：托盘显示"轮到你了，用说的或打字回答"，输入框获得焦点高亮。确认类提问：托盘里三个按钮。
- 答对的庆祝要克制：卡片勾选动画 + 视频框边缘一次柔光 + 可选提示音；不显示"已掌握"之类结论。

#### 5.6.8 控制坞

**始终单行**，高 76px，按钮最小 44×44px，从左到右三组：

1. **说**：圆形麦克风按钮（56px）。按住说话（指针，或焦点不在输入框、按钮、选项卡片上时按住空格）；状态：空闲 / 准备中 / 正在听（变色 + 随音量脉动的外环）/ 发送中 / 不可用（带原因）。"免提"开关：开启时显示"免提已开，直接说话"，加载语音检测时显示"正在开启…"。"打断"按钮固定占位（不讲话时禁用，不移除）。
2. **写**：输入框（带发送按钮）+ 快捷回应芯片（没听懂 / 举个例子）+ "更多回应"菜单（给点提示、看答案、再讲一遍、我会了、休息一下）。芯片点击后短暂显示"已发送"，并在"老师刚才说的 / 对话记录"里出现一条学生消息。
3. **课堂**：字幕开关、音量（图标，点开是滑杆浮层与静音）、课堂设置（讲法菜单显示当前讲法，初值来自课堂状态 **[B1]**；"讲慢点 / 讲快点"也在这里）、对话记录、暂停、下课（危险色）。

宽度不够时按课堂根容器宽度折叠（容器查询），**不换行**：先把两个芯片收进"更多回应"，再把对话记录按钮移到顶栏；输入框最窄 240px。

麦克风错误按原因分三种文案（没给权限 / 找不到麦克风 / 其他），并给"怎么开启权限"的说明。语音识别没配置时，麦克风按钮禁用并在旁边写明原因，给"去开启"（新标签页打开设置，不离开课堂）。

#### 5.6.9 对话记录

抽屉（宽屏为常驻第三列）。老师说的每一句、学生说的每一句（语音识别结果标"语音"，打字标"文字"，快捷回应标动作名）按时间排列；识别中显示占位。**只存在内存里**，不落盘、不进日志（隐私红线）。回声提示改为单独的一次性提示。只读最小版（见 §5.6.5）在 U2，完整版在 U6。

#### 5.6.10 键盘与声音

- 快捷键：按住空格说话（焦点不在输入框、按钮、选项卡片上时）、Esc 打断、回车提交；**作答托盘打开且焦点不在输入框时，A–H 与 1–9 只用于选选项**；字幕、静音、对话记录是 `Shift+C`、`Shift+M`、`Shift+T`；`?` 打开快捷键面板。
- 提示音（合成的短音，默认开、音量低、可在设置里关）：接通、轮到你了、开始录音、结束录音、答对、答错（柔和）、下课。见 `spec/design-system.md` §9。

#### 5.6.11 课内进度

顶栏显示分段进度条和"要点 2/4 · {要点名}"。"要点"是教案里各段的要点摊平后的序列（一节课通常只有一两个知识点，按"段"算会永远是 1/1），数据来自教案与课堂状态 **[B1]**，不由模型口述。数据缺失时顶栏只显示课题。

#### 5.6.12 断线与出错

- 重连不设次数上限：指数退避（上限 15 秒），舞台遮罩显示"连接中断，正在重连…（第 n 次）"和"立即重试"。
- 本机服务重启过：遮罩说明原因；密钥库被锁时给出解锁入口，解锁后回到课堂；不得停在遮罩上没有去向。
- 出错后的"继续"沿用本节课原来的语音或文字方式。
- "这节课已在另一个标签页打开"时提供"在这里继续" **[B14]**；旧标签页显示"已在别处继续"。
- 所有错误文案走错误码映射；不直接显示异常原文。

#### 5.6.13 窄屏与手机

- **768–1099px**：自动使用"白板优先"视图（老师为左上角小窗，约 160×284px，可切回并排）。
- **< 768px（手机竖屏）**：两种模式，点击切换，默认"老师模式"。

- U2 只保证窄屏与手机上可用（单列、视频不裁成横条、控制坞固定在底部）；上面的通话式布局在 U6。

### 5.7 课后小结（`ended`）

**目的**：让学生带走"今天学会了什么、哪里还不稳、下一步做什么"。这是一节课情绪最高的时刻。

**容器**：小结到达后，同一路由从课堂外壳过渡到专注外壳的浅色容器（交叉淡化）：不显示站点导航，内容区最大宽 880px，允许页面纵向滚动，顶部只有"回到今天"和课题。U2 只把现有小结内容放进这个容器；U3 按本节重做内容。

```text
┌──────────────────────────────────────────────────────────────────────┐
│ ← 回到今天                                                           │
│ [老师小窗：表扬或道别后回待机]   课后小结                             │
│                                 {课题} · 11 月 21 日 · 上了 24 分钟  │
├──────────────────────────────────────────────────────────────────────┤
│ 今天你做到了                                                          │
│  要点 4 / 4     答对 5     提示后答对 1     看了答案 1                │
│  有 2 处换了讲法，回头补了 1 个前面的知识点                           │
├──────────────────────────────────────────────────────────────────────┤
│ 老师的小结   （模型写的小结文本）                                     │
├──────────────────────────────────────────────────────────────────────┤
│ 掌握的变化                                                            │
│  {知识点 A}   ▓▓░░░░ → ▓▓▓▓░░   在学 → 不稳       再讲一遍            │
│  {知识点 B}   ▓▓▓░░░ → ▓▓▓▓▓░   不稳 → 已掌握                         │
├──────────────────────────────────────────────────────────────────────┤
│ 接下来                                                                │
│  [ 下一节：{标题}（周三）]   新增 3 张复习卡 · 去复习   回放这节课    │
│  计划已调整：{变化摘要}  查看                                         │
├──────────────────────────────────────────────────────────────────────┤
│ ▸ 白板笔记      下载白板                                              │
└──────────────────────────────────────────────────────────────────────┘
```

- "今天你做到了"的数字、"掌握的变化"、"接下来"都来自小结接口 **[B2]**：作答情况按该课堂的作答证据统计；换讲法与回补的次数由事件计数；掌握变化取该课堂第一条证据的课前值与最后一条的课后值，没有作答证据的知识点不出现；"下一节"取当前计划里下一个未完成条目；"计划已调整"只在这节课之后确实产生了新版本时出现。新增复习卡数没有数据的旧课堂不显示这一行。
- 中途放弃的课用不同的标题与文案（"这节课先上到这里"），不显示"你做到了"式的统计，只给"继续这节课"与"回到课程"。
- 收到小结时使课程仪表盘、计划、进度的缓存失效。

### 5.8 回放与示例课

**共同点**：复用课堂外壳和老师舞台——**回放里必须有老师**。形象姿态由回放事件驱动（同一套状态函数）；字幕在视频框里；白板与课堂一致。控制坞换成回放控件：播放 / 暂停、进度条（按时间显示，不是事件序号）、倍速、字幕、"下载白板"。

**示例课（`/sample-lesson`）**

- 顶栏常驻标识"预生成内容 · 可离线回放"（防空壳规则要求明确标注）。
- 遇到题目时用选项卡片作答，按所选分支继续（现有逻辑）。
- **声音**（默认决定 D11）：联网时用所选老师的音色逐句合成（与选老师页试听同一条通路：只读、不写任何业务数据、不建立实时连接）；合成失败或离线时退回浏览器自带朗读并标注"浏览器朗读"。示例课仍然不调用教学引擎与模型。对应的端到端约束改为"不产生写入业务数据的请求、不建立实时连接（语音合成请求除外）"。
- 结束时：小结 + 主按钮"连接 AI 服务，用自己的资料上课"。

**课程记录（`/courses/:id/history`）**：按日期分组的时间线卡片——课题、日期、时长、状态徽标（上完 / 中途离开）、小结首句、"回放"**[B6]**。"旧版对话"区块在没有旧数据时整块隐藏。

### 5.9 复习与错题本

**复习页（`/courses/:id/review`，带课程标签栏）**：到期数、"开始复习"、错题本。

**复习会话（`/courses/:id/review/session`，FocusShell）**

- 顶部进度："第 3 / 12 张" + 进度条。
- 一张卡片居中：闪卡是"正面 → 显示答案 → 背面 + 四个自评按钮"；题目卡是"题干 + 选项卡片 + 提交 / 我不会"。
- **答后反馈（新增的一拍）**：提交或自评后停在结果态——对错判定、解析、"下次复习：3 天后"、该知识点掌握度的变化（课前值需要后端补充 **[B15]**；其余数据后端已经返回，现在被丢弃）；再点"下一张"。归档的卡片提示"这道错题已经稳了，收起来了"。
- **结束页**：本次做了几张、对几张、归档几张、涉及知识点的掌握变化、下一批什么时候到期；按钮"回到今天"。

**错题本**

- 按知识点分组，每组显示错题数；每道错题：日期、题干、当时的答案、判定、原因。
- 每道题两个动作："现在重做"与"让老师再讲一遍这个知识点"（走现有的按知识点开课通道，进入候课）。
- 筛选项的选项来自未过滤的数据。

### 5.10 练习与模考（FocusShell）

- **开始页**：题量、时长、覆盖的知识点 **[B7]**，一句规则说明，主按钮"开始计时"。
- **作答**：一题一屏；底部题号条（已答 / 未答 / 标记）；顶部倒计时（最后 5 分钟变色，最后 1 分钟提示一次；读屏播报改为每分钟与最后 10 秒）；每题的保存状态可见（已保存 / 保存中 / 保存失败 · 重试）——**保存失败不得静默**；刷新后回到原来的题并回填已选答案 **[B7]**。计时以服务端截止时间为准。
- **结果页**：得分环；按知识点的对错分布；逐题卡片（题干、你的答案、正确答案、解析、"老师讲评"三个动作）。讲评用老师的声音 **[B13]**。底部说明"答错的题已加入复习"和"看看进度"。

### 5.11 进度（`/courses/:id/progress`）

回答"我进步了多少、离目标还差什么"。全部来自作答证据；没有证据时是空状态，不显示一排 0。

1. **保分条**：预计已保住分值 / 满分，带目标线；没有真题统计或没有考试时不显示这一项。
2. **掌握度方格图**：按单元分组，每个知识点一格；颜色与形状 = 状态（取后端）；格子边框粗细或角标 = 考试权重。点格子看该知识点的作答历史 **[B5]** 并可"再讲一遍"。
3. **学习日历**：最近 8 周，哪天有作答记录（复用进度接口已有的按天数据）；连续学习天数由日期算出。
4. **每周学习时长**柱状图 **[B5]**（可选项，排在最后做）。
5. 三个数字：已学分钟、已掌握知识点数、已上课节数。

### 5.12 老师（`/tutors`）

样张：`reference/mockups/tutors.html`。

**画廊**：竖向大卡片（立绘，悬停或聚焦时播放待机循环），卡片下方：名字、一词气质、"当前老师"角标；卡片描边用各自老师的主题色。最后一张是"＋ 导入角色"（支持拖放，高亮）。

**选中后的展示编排**（首次引导与画廊共用）：问候 → 讲解片段并同步播放**该老师的专属台词**（优先口头禅第一条，用 TA 自己的声音）→ 表扬动作 → 回到待机。旁边的信息：一词气质、名字、一句话定位、代表台词气泡（可重听）、"TA 会这样教你"（默认讲法的人话解释）、三个动作试演小按钮（讲解 / 点赞 / 安抚）、主按钮"就选 {name}"（已是当前老师时显示"当前老师"）。选定时老师回应一句问候（来自角色数据）。

**六位内置老师的声音必须互不相同**（现状初棠与澜音共用同一个音色）。

**详情（`/tutors/:tutorId`）三个标签**

- **认识 TA**：上面的展示 + "设为我的老师"。
- **调整人设**：名字、角色设定、性格（标签式输入，前端限制数量与长度）、口头禅、默认讲法、TA 的声音（音色列表选择 + 试听 + 语速滑杆）、主题色（预设色板，仅自定义角色）。内置老师可编辑，并提供"恢复默认" **[B8]**。只改名字时不要连带提交形象档位。
- **形象与素材（高级）**：形象效果（静态 / 动态 / 实时）、短片完整度、本地实时驱动、导出短片提示词、许可与作者。面向创作者。

**导入**：拖入图片或角色包 → 三步小向导（起名 → 性格与讲法 → 选声音）→ "设为我的老师"。

**老师在全应用的出现位置**（E1）：顶栏老师小卡；今天页与课程中枢的问候条；课程准备流程的读资料与访谈；候课；空状态与加载态的立绘与一句话；课后小结；练习讲评；解锁页。小尺寸场景默认用静态立绘，进入视口或悬停时才播放循环，**同屏最多一个在播放的老师视频**，离屏暂停。

### 5.13 设置（`/settings/:section`）

左侧分区导航（当前分区高亮），右侧一次只显示一个分区。

| 分区 | 内容 |
| --- | --- |
| **我** | 称呼、当前阶段、讲解节奏、反馈方式、兴趣。显式保存（有未保存更改时底部出现保存条） |
| **老师与声音** | 当前老师（去老师页）、TA 的音色、语速滑杆、提示音开关 |
| **AI 服务** | 顶部**就绪总览**（讲课 / 读资料 / 检查答案 / 看图 / 语音 五项，各带修复入口）；已连接的服务；"添加服务"（连接向导）；"测试对话"（原"试聊"）；*高级*：按能力分配模型、额外参数 |
| **麦克风与识别** | 麦克风测试（电平 + 识别结果）；识别方式两张卡片：在线识别 / 离线识别（下载 163 MB，声音不出本机，带进展）；安装命令收进"排障" |
| **隐私与数据** | 主密码；数据存在哪里；"只在本机运行"的说明 |
| **高级** | 实时形象驱动、云端实时护栏、分析并发数、用量明细 |

表单规范见 `spec/design-system.md` §8。

### 5.14 通用状态

| 状态 | 规格 |
| --- | --- |
| 加载 | 0.4 秒内不显示任何加载指示；之后显示骨架，至少显示 0.4 秒；页面重做时骨架与最终布局同形 |
| 空 | 老师立绘（或图标）+ 一句老师口吻的话 + 一个动作按钮。不出现只有一行灰字的空状态，也不出现"什么都不渲染"；加载未结束时绝不显示空状态 |
| 错误 | 人话标题 + 一个必有的动作（重试 / 去设置 / 返回）+ 可展开的技术详情；按错误码映射文案；不直接显示服务端原文 |
| 进行中 | 按钮内转圈 + 原文案 + 忙碌标注，按钮宽度不变；禁用（条件不满足）与进行中是两种样式，禁用不显示等待光标 |
| 成功 | 就近确认 + toast（约 5 秒，悬停暂停）；可撤销的操作在 toast 里带"撤销" |
| 确认 | 应用内确认对话框（标题说动作，正文写出对象与后果，默认焦点在安全选项）；全应用不出现浏览器原生的确认框 |
| 离线 / 后端不可达 | 顶部细条"连接不上本机服务，正在重试…"，恢复后自动消失 |
| 锁定 | 专注外壳：当前老师的立绘 + 一句"输入主密码，我们接着学" + 密码框与"解锁"；不显示导航 |
| 404 | "这一页不存在" + 一个按钮（U0 回课程列表，U3 起回"今天"；老师立绘 U4 加入） |
| 渲染异常 | 按路由的错误边界：保留外壳与导航，内容区显示错误与返回按钮 |

## 7. 让个性化与进步看得见

### 7.1 计划理由（数据拼句，不由模型生成）

每个计划项的每个知识点有考试权重与当前掌握两个值。界面用两条小横条 + 一句话模板表达，模板按两者的高低组合选取，例如：

- 权重高、掌握低："这部分考得多，你现在还不太稳，所以排在前面。"
- 权重高、掌握高："这部分考得多，你已经比较稳了，安排一次巩固。"
- 权重低、掌握低："考得不多，但它是后面内容的基础。"（仅当它是后续知识点的前置时）
- 老师划过重点："你说老师划了这里。"

模板带占位符放文案文件；不得出现具体学科内容。

### 7.2 计划变化

计划每次重排产生新版本。界面在三个地方说出来：课后小结的"计划已调整"、课程今日页的提示条、计划页的说明条。变化用"提前了 / 延后了 / 新排进来 / 暂缓"四类列出条目名；原因映射成人话。比较两版时按（类型，知识点集合）对应条目，不按条目 id（每次重排都会换）。

### 7.3 掌握度

四态只认后端的状态；颜色、形状与图标全应用一致（见设计系统规格 §2.4）。出现的位置：地图每个知识点、进度方格图、课后小结的变化、摸底起点图、复习答后反馈。

### 7.4 课上的调整

见 §5.6.6"调整要看得见"与 §5.7"有 n 处换了讲法、回头补了 m 个前面的知识点"。

### 7.5 "不懂可以反复教"

出现的位置：课堂的"没听懂""再讲一遍""从这一行开始没跟上"；错题本的"让老师再讲一遍"；地图与进度里知识点的"再讲一遍"；课后小结里"还不稳"的知识点旁的"再讲一遍"。这些入口都走现有的按知识点开课通道，不新增由模型即兴出题的捷径。

## 10. 不做清单（U 阶段内不得开工，除非所有者另行批准）

- 产品内的演示模式或假数据引导；组件陈列页不进产品路由与生产构建。
