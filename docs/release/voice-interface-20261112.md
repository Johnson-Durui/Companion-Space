# 语音接口接入 · 2026-11-12

本轮将语音接入做成可操作的页面和可调用的 API。入口为「声音与模型 → 语音接口配置」（`/providers#voice-service`），角色工作室提供直达链接。配置步骤、字段说明和请求示例见 [语音服务接入](../voice-service.md)。

## 使用结果

- 可以新建或修改本地 Qwen 语音连接，填写 Base URL；注册连接无需修改 `.env`。在线连接沿用项目支持的协议和加密保险箱。
- 可以读取模型列表，填写模型名、声线 ID、语速和试听文本，再请求实际合成；失败原因会显示在页面。
- 可以停止播放，修改参数后旧结果不会重新播放。页面同时支持桌面和 390px 宽度。
- 可以将连接与模型绑定到所选空间的 TTS。试听字段与角色长期配置分开，页面提供角色声线设置链接。
- 提供经过 Owner 鉴权的 `POST /api/v1/providers/connections/{connection_id}/speech-preview`，返回 24 kHz 单声道 PCM16。接口页显示当前参数的调用示例。

## 实现边界

新增语音面板、API 客户端函数、请求模型和服务端合成入口；复用已有 Provider 适配器、音频播放队列、空间分配和 Vault。声线预设提取为共享的小模块，角色试听继续使用原有实现。没有新增依赖。

本地连接仅允许公网、loopback、RFC1918 和 IPv6 ULA 地址，仍使用 DNS 固定连接和地址检查；远程服务和既有 Ollama 保留原有地址策略。浏览器跨端口调用只新增暴露采样率、声道两个响应头，允许来源策略不变。

停止试听的 HTTP 断开会取消并等待后端合成任务，触发本地适配器的推理取消请求。同页两个连接编辑入口会同步已保存的连接字段，防止用旧表单覆盖新地址；普通外部更新保留试听参数，删除连接后回到新建状态。

试听文本最多 240 字符，输出最多 10 MiB，服务端校验非空及完整 PCM16 样本。试听接口收齐音频后响应；现有实时会话协议不变。
