## 启动

解压后在项目根目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r services/api/requirements.txt
npx.cmd --yes npm@11.21.2 ci
.\START-LOCAL-WINDOWS.ps1 -Production
```

浏览器访问 `http://127.0.0.1:3000`。首次设置本地保险箱主密码，从「今日 → 进入我的书房」开始。之后仅需运行最后一条启动命令。Python 3.13 用户将第一行改为 `py -3.13`。完整说明及端口、权限与恢复方法见 [Windows 使用说明](../../WINDOWS-README.md)。

## 归档与校验

交付文件名为 `Companion-Space-20261111.zip`，同目录提供 `.zip.manifest.json` 与 `.zip.sha256`。ZIP 内有 `DELIVERY-MANIFEST.json`，记录逐文件 SHA256 和 VRM 哈希。归档排除数据库、.env、密钥、依赖目录、构建缓存、原软件取证资料与未发布的 painted 原始纹理；保留许可证与原创迁移说明。

```powershell
Get-FileHash .\Companion-Space-20261111.zip -Algorithm SHA256
```

将结果与旁边的 `.sha256` 文件核对。重新生成时使用 `scripts/package_delivery.py --output outputs/<新名称>.zip`；已有同名产物拒绝覆盖。
